# Instruções do projeto — Curadoria Prime (kit público de boot editorial)

Você está no repositório de boot editorial da **Curadoria Prime** (reviews e comparativos de tecnologia, Brasil). Antes de produzir qualquer artigo, edição ou HTML:

1. Leia `CHECKLIST-EEAT-PUBLICO.md` e siga-o integralmente.
2. Use `ARTIGO-A-GUTENBERG.html` como referência de estrutura (blocos `wp:html` com CSS inline, cabeçalho doc-only com campos de SEO, Schema JSON-LD ao final).
3. Leia o `README.md` para entender o que este repo contém e o que fica de fora por estratégia.

## Regras inegociáveis

- **NUNCA simular posse ou teste físico de produto.** Análises usam pesquisa técnica + testes publicados por terceiros + dados agregados de compradores verificados. O selo "✅ Testado por nós" é reservado para testes reais futuros.
- **Preço sempre com data de verificação** explícita no artigo.
- **Links de afiliado sempre com `rel="sponsored"`** e aviso de comissão no topo do artigo.
- **Antialucinação:** só citar fonte, vídeo ou avaliação cuja existência foi confirmada.
- Todo artigo fecha com a seção **"📚 Fontes consultadas"**.

## Fora de escopo deste repositório

Dados estratégicos (handoff de sessão, roadmap de pautas, log-mestre de decisões, packs de preços) vivem no repositório privado da operação. **Nunca os escreva nem os peça para serem salvos aqui.**
