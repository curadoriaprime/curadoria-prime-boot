🚚 Portabilidade do agente: como levá-lo para o Claude.ai e o VS Code

Guia interativo para usar o agente editorial da casa em outros ambientes — grátis ou com custo baixo. O agente é um kit de arquivos + regras (sem código), então funciona em qualquer ferramenta que aceite instruções e arquivos. Todo este material vive na pasta PORTABILIDADE/, separado do kit original.

💡 Conceito 🧭 Qual caminho? 🛤️ Os 4 caminhos 📋 Blocos prontos 📁 Estrutura 💰 Custos ✅ Checklist ❓ FAQ ⚠️ O que não levar

💡 Por que o agente é portátil

O "agente Curadoria Prime" não é um programa: é um kit de boot — arquivos de referência + regras editoriais + uma mensagem de ativação. Só muda o mecanismo de entrega em cada ambiente.

📦

O agente = 3 arquivos + regras

README.md (visão do kit), CHECKLIST-EEAT-PUBLICO.md (padrões E-E-A-T obrigatórios) e ARTIGO-A-GUTENBERG.html (modelo de estrutura dos artigos).

🔁

O que muda de um ambiente para outro

No Agent Mode o agente baixa as URLs raw sozinho. No Claude.ai os arquivos vão anexados. No VS Code eles já estão locais no workspace.

🧱

Tudo separado do kit original

Os 4 arquivos da raiz seguem intocados. Este guia, os blocos adaptados e os modelos de regras vivem só na pasta PORTABILIDADE/ — removível sem efeito colateral.

🛤️ Os 4 caminhos, passo a passo

Escolha a aba. Cada caminho lista pré-requisitos, passos e avisos.

Caminho 1 — Claude.ai com Projects (o mais confortável)

Grátis com limites · Pro ~US$ 20/mês opcional
  1. Em claude.ai, abra Projects → New project (ex.: “Curadoria Prime — Editorial”).
  2. Em Project knowledge, suba os 3 arquivos do kit: README.md, CHECKLIST-EEAT-PUBLICO.md, ARTIGO-A-GUTENBERG.html.
  3. Em Project instructions, cole a essência das regras (o texto de vscode/copilot-instructions.md serve igual): regra-mãe de honestidade, preço com data, afiliado sinalizado, antialucinação.
  4. Pronto: todo chat iniciado dentro do projeto herda arquivos + instruções — nunca mais precisa colar bloco de boot.
⚠️ No plano Free, Projects tem limite de quantidade (~5 projetos) e capacidade menor de arquivos. Se a sua conta não exibir Projects ou estourar a cota, use o Caminho 2. O plano Pro (~US$ 20/mês) libera projetos ilimitados e RAG automático.

Caminho 2 — Claude.ai chat simples (sempre funciona)

Grátis (com limite de mensagens)
  1. Abra um novo chat no claude.ai e anexe os 3 arquivos do kit (o plano Free permite anexos por conversa).
  2. Cole o conteúdo do bloco adaptado (aba 📋 Blocos prontos → Claude.ai) como 1ª mensagem.
  3. Peça para o agente confirmar a leitura e resumir o padrão da casa antes de produzir qualquer coisa.
⚠️ Não use o BLOCO-URLS-PARA-PROMPT.txt aqui: o chat do claude.ai não faz fetch confiável de URLs raw — esse bloco é exclusivo do Agent Mode. Por isso o bloco adaptado usa anexos.

Caminho 3 — VS Code com GitHub Copilot (Free)

Grátis para sempre: ~50 chats/mês + 2.000 conclusões
  1. Instale a extensão GitHub Copilot no VS Code e entre com sua conta GitHub (plano Free).
  2. Abra este repositório como workspace (git clone + File → Open Folder).
  3. No Copilot Chat, cole o bloco adaptado (aba 📋 Blocos prontos → VS Code) como 1ª mensagem.
  4. (Opcional, recomendado) Copie PORTABILIDADE/vscode/copilot-instructions.md para .github/copilot-instructions.md na raiz do repo — daí o Copilot carrega as regras da casa automaticamente em todo chat.
⚠️ O limite do Free (~50 mensagens de chat/agente por mês) acaba rápido em produção intensa. Se estourar: aguarde o reset mensal, use o Caminho 4 ou avalie o Copilot Pro (~US$ 10/mês).

Caminho 4 — VS Code com Cline / Roo Code / Kilo Code (custo zero ou quase)

Extensão grátis · modelo grátis (Gemini/OpenRouter) ou centavos por uso
  1. Instale a extensão Cline (ou Roo Code / Kilo Code) — grátis e open source.
  2. Configure o provedor do modelo (BYOK — bring your own key):
    • Custo zero: chave gratuita do Google AI Studio (Gemini) ou modelos gratuitos do OpenRouter;
    • Custo baixo: chave pay-per-use (Anthropic, OpenRouter etc.) — paga só os tokens usados, tipicamente centavos por sessão.
  3. Abra este repo como workspace e cole o bloco adaptado (aba 📋 Blocos prontos → VS Code) como 1ª mensagem.
  4. (Opcional, recomendado) Copie PORTABILIDADE/vscode/clinerules para .clinerules na raiz do workspace — as regras passam a ser lidas automaticamente.
  5. Bônus: aqui o agente também cria/edita arquivos HTML no repo e roda comandos — ideal para produção em lote de artigos.
💡 Nas cotas gratuitas de API há limites diários de requisições; para rotina pesada, a chave pay-per-use costuma custar menos que uma assinatura.

📋 Blocos prontos (copiar e colar)

Versões limpas, sem as linhas de instrução. Cada botão copia o texto completo.

BLOCO-CLAUDE-AI · 1ª mensagem no Claude.ai (com os 3 arquivos anexados)

4. Citações e vídeos: só fontes cuja existência você confirmou (antialucinação).

❓ Perguntas frequentes

O bloco de URLs (BLOCO-URLS-PARA-PROMPT.txt) funciona no Claude.ai?
Não de forma confiável — ele depende de o agente fazer fetch das URLs raw, o que só o Agent Mode garante. No Claude.ai, anexe os 3 arquivos e use o BLOCO-CLAUDE-AI.txt. No VS Code os arquivos já são locais, então use o BLOCO-VSCODE.txt.
Preciso pagar o Claude para usar Projects?
Não. Contas Free têm Projects com limites (cerca de 5 projetos e capacidade menor de arquivos). O plano Pro (~US$ 20/mês) libera projetos ilimitados e RAG automático quando a knowledge satura. Se Projects não aparecer na sua conta, siga o Caminho 2 (chat com anexos).
Estourei os 50 chats/mês do Copilot Free. E agora?
Três saídas: aguardar o reset mensal, migrar para o Caminho 4 (Cline com chave própria — grátis ou centavos) ou assinar o Copilot Pro (~US$ 10/mês). Para produção editorial intensa, o Caminho 4 costuma ser o melhor custo-benefício.
Preciso colocar .clinerules / .github/ na raiz?
Só se quiser o carregamento automático das regras — é exigência das ferramentas (Copilot lê .github/copilot-instructions.md; Cline/Roo/Kilo leem .clinerules na raiz do workspace). Sem isso, basta colar o bloco de boot na 1ª mensagem de cada sessão.
Posso apagar a pasta PORTABILIDADE/ depois?
Pode. Ela é 100% isolada: os 4 arquivos do kit na raiz não dependem de nada daqui, e o boot do Agent Mode continua funcionando igual.
O agente no Claude.ai/VS Code pode acessar meu repo privado (handoff, preços)?
Não automaticamente — e é assim que deve ser. Esses dados não vivem neste repo público. Quando precisar deles em alguma ferramenta, anexe à parte, como no fluxo do Agent Mode, e prefira ambientes onde você controle a retenção de dados.

⚠️ O que NÃO levar

Este repo público não contém — e nenhuma ferramenta externa deve receber sem necessidade: handoff de sessão, roadmap de pautas, log-mestre de decisões e packs de preços. Quando esses dados forem necessários em alguma ferramenta, eles devem ser anexados à parte (vindos do repositório privado da operação), nunca salvos aqui nem colados em ambientes sem controle de retenção.
